# 손글씨 숫자 인식기 (Handwritten Digit Recognizer)

마우스로 0~9 숫자를 쓰면, 인공 신경망(Artificial Neural Network)이 어떤 숫자인지 맞히는 예제입니다.

> 📘 사용한 방법론(다층 퍼셉트론, 학습 원리, 평가 지표)과 전체 절차는 **[방법론_설명.md](방법론_설명.md)**에 자세히 정리되어 있습니다.

## 준비물

- Python 3.10 이상
- 필요한 라이브러리(Library) 설치:

```bash
pip install scikit-learn joblib numpy pillow
```

`tkinter`(창을 만드는 도구)는 윈도우용 Python에 기본으로 들어 있습니다.

## 실행 순서

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 1 | `1_모델_학습하기.py` | MNIST 사진 6만 장으로 모델을 학습(Training)하고 `숫자_인식_모델.joblib`로 저장 |
| 2 | `2_손글씨_숫자_인식하기.py` | 그림판 창을 열어 직접 쓴 숫자를 인식(Inference) |

```bash
python 1_모델_학습하기.py        # 처음 한 번만 (1~3분)
python 2_손글씨_숫자_인식하기.py   # 숫자 쓰고 놀기
```

## 그림판 사용법

- 검은 칸에 마우스 왼쪽 버튼으로 숫자 하나를 **크게** 씁니다. 손을 떼면 바로 결과가 나옵니다.
- **지우기**: [지우기] 버튼, `Delete` 키, 또는 마우스 오른쪽 클릭
- **종료**: 창 닫기 또는 `Esc`

## 어떻게 동작하나요?

1. **전처리(Preprocessing)**: 내가 쓴 280×280 그림을 MNIST와 같은 규칙으로 바꿉니다.
   숫자 부분만 잘라 20픽셀 크기로 줄이고, 28×28 칸의 가운데(무게중심, Center of mass)에 놓습니다.
2. **추론(Inference)**: 784개(28×28) 픽셀 값을 신경망에 넣으면 0~9 각각의 확률(Probability)이 나옵니다.
3. 가장 확률이 높은 숫자를 답으로 보여 줍니다.

> `숫자_인식_모델.joblib`는 1단계를 실행하면 만들어지는 파일이라 저장소에는 올리지 않습니다.
