## 2. 문제 정의: 이것은 어떤 문제인가?

머신러닝 문제를 풀 때 가장 먼저 할 일은 **무엇을 예측하는지** 정하는 것입니다.

| 구분 | 예측하는 것 | 예시 |
|---|---|---|
| **회귀(Regression)** | 연속된 숫자 | 집값, 매출액, 내일 기온 |
| **분류(Classification)** | 정해진 범주 중 하나 | 스팸/정상, 고객 이탈 여부, **숫자 0~9** |

손글씨 숫자 인식은 "이 사진이 0~9 중 무엇인가?"를 고르는 문제입니다.

- 범주 중 하나를 고르므로 **분류**입니다.
- 범주가 10개이므로 **다중 클래스 분류**입니다. 2개면 이진 분류(Binary Classification)라고 합니다.
- 사진마다 정답(라벨, Label)이 붙어 있으므로 **지도 학습**입니다.

> 💡 **주의:** 숫자 '7'을 예측하지만 이것은 회귀가 아닙니다. 모델 입장에서 0~9는 크기가 있는 수가 아니라 **이름표 10개**입니다. 7을 8로 틀리는 것과 1로 틀리는 것은 똑같이 '틀림'입니다.

## 4. 데이터: MNIST

**MNIST**는 미국 국립표준기술연구소(NIST)가 모은 손글씨 숫자 사진을 정리한 데이터셋입니다. 머신러닝 분야의 'Hello, World'로 불릴 만큼 널리 쓰입니다.

- 사진 70,000장: 학습용 60,000장, 시험용 10,000장
- 사진 한 장 = 가로 28 × 세로 28 = **784개 픽셀**
- 픽셀 값 = 0(검정) ~ 255(흰색)의 밝기
- 검은 배경에 흰 글씨, 숫자는 가운데 정렬

### 사진을 '표'로 바라보기

분류 수업에서 다루는 표 형태 데이터와 똑같이 생각할 수 있습니다.

| | 픽셀1 | 픽셀2 | … | 픽셀784 | **정답(y)** |
|---|---|---|---|---|---|
| 사진 1 | 0 | 0 | … | 0 | **5** |
| 사진 2 | 0 | 0 | … | 0 | **0** |
| ⋮ | | | | | |
| 사진 60,000 | 0 | 0 | … | 0 | **8** |

- 행(Row) = 표본(Sample) 하나 = 사진 한 장
- 열(Column) = 특징(Feature) = 입력 변수 하나 = 픽셀 하나
- 마지막 열 = 목표 변수(Target)

즉 이 예제는 **"입력 변수 784개로 범주 10개 중 하나를 예측하는 분류 문제"**입니다. 고객 정보 20개로 이탈 여부를 예측하는 문제와 구조가 같고, 변수와 범주가 더 많을 뿐입니다.

## 5. 데이터 분할: 학습 / 검증 / 시험

모델이 **외워서** 맞히는지, **이해해서** 맞히는지 알려면 공부할 때 본 적 없는 문제로 시험해야 합니다.

| 데이터 | 개수 | 비유 | 용도 |
|---|---|---|---|
| 학습(Training) | 54,000장 | 교과서 | 가중치를 고치는 데 사용 |
| 검증(Validation) | 6,000장 | 모의고사 | 학습 도중 성능 점검, 언제 멈출지 결정 |
| 시험(Test) | 10,000장 | 수능 | 맨 마지막에 **딱 한 번** 최종 성능 측정 |

- MNIST는 학습용 60,000장과 시험용 10,000장이 처음부터 다른 파일로 나뉘어 있습니다.
- 검증용 6,000장은 `validation_fraction=0.1` 설정에 따라 sklearn이 학습용에서 10%를 자동으로 떼어 냅니다.

> ⚠️ **데이터 유출(Data Leakage):** 시험 데이터를 보고 설정을 바꾸거나 다시 학습하면, 시험 점수가 실제 실력보다 높게 나옵니다. 설정을 조정할 때는 검증 데이터만 봐야 합니다.

## 6. 전처리: 평탄화와 정규화

### 6-1. 평탄화(Flatten)

MLP는 입력을 **한 줄짜리 목록**으로만 받습니다. 그래서 28×28 격자를 한 줄로 펴서 784칸으로 만듭니다.

```
 28×28 격자                 784칸 한 줄
 ┌──────────┐
 │ 1번째 줄  │  ─┐
 │ 2번째 줄  │   ├─▶ [1번째 줄 | 2번째 줄 | ... | 28번째 줄]
 │   ...     │   │
 │ 28번째 줄 │  ─┘
 └──────────┘
```

이렇게 펴면 **"어떤 픽셀이 어떤 픽셀과 위아래로 붙어 있었는지"** 하는 공간 정보를 모델이 직접 알 수 없게 됩니다. 이것이 MLP의 한계이고, 이를 보완한 것이 [14장](#14-머신러닝과-딥러닝-그리고-다음-단계)의 CNN입니다.

### 6-2. 정규화(Normalization)

픽셀 값 0~255를 255로 나눠 **0~1** 사이로 맞춥니다. 이를 최소-최대 정규화(Min-Max Scaling)라고 합니다.

**왜 필요한가요?**
- 신경망은 입력에 가중치를 곱해 더하는 계산을 여러 층에 걸쳐 반복합니다.
- 입력 값이 크면 중간 결과가 너무 커지고, 기울기(Gradient)가 들쭉날쭉해져서 학습이 불안정해집니다.
- 입력을 작고 고른 범위로 맞추면 학습이 빠르고 안정적입니다.

> 💡 **전처리는 학습할 때와 사용할 때 똑같이 해야 합니다.** 2단계 그림판에서도 그린 그림을 255로 나눕니다. 한쪽만 나누면 모델은 처음 보는 형태의 입력을 받게 되어 엉뚱한 답을 냅니다.

## 7. 모델: 다층 퍼셉트론(MLP)

### 7-1. 뉴런 하나가 하는 일

인공 뉴런은 아주 단순한 계산 장치입니다.

```
 x1 ──(× w1)──┐
 x2 ──(× w2)──┼──▶ [ 합계 + b ] ──▶ [ 활성화 함수 ] ──▶ 출력
 x3 ──(× w3)──┘
```

1. 입력(x)마다 **가중치(Weight, w)**, 즉 '이 입력이 얼마나 중요한가'를 곱합니다.
2. 모두 더한 뒤 **편향(Bias, b)**을 더합니다. → `z = w1·x1 + w2·x2 + w3·x3 + b`
3. **활성화 함수**를 통과시킵니다. → `출력 = ReLU(z)`

**계산 예시**

입력 x = (0.5, 0.8), 가중치 w = (0.4, −0.2), 편향 b = 0.1일 때

- z = 0.4×0.5 + (−0.2)×0.8 + 0.1 = 0.2 − 0.16 + 0.1 = **0.14**
- ReLU(0.14) = **0.14** (z가 음수였다면 0)

> 📌 출력층에 시그모이드를 쓰는 뉴런 하나는 **로지스틱 회귀(Logistic Regression)**와 같습니다. MLP는 로지스틱 회귀와 비슷한 작은 판단 장치를 수백 개 모아 여러 층으로 쌓은 모델이라고 볼 수 있습니다.

### 7-2. 층을 쌓은 구조

```
 입력층          은닉층 1         은닉층 2        출력층
 (784개)         (256개)          (128개)         (10개)

  픽셀1  ○ ─┐
  픽셀2  ○ ─┼──▶  ○ ×256  ──▶  ○ ×128  ──▶  ○ ×10  ──▶ 소프트맥스 ──▶ 0~9 확률
   ...      │     (ReLU)        (ReLU)
  픽셀784 ○ ─┘

         작은 특징 찾기    특징 조합하기    숫자별 점수
         (획, 곡선)        (고리, 꺾임)
```

| 층 | 뉴런 수 | 역할 |
|---|---|---|
| 입력층 | 784 | 픽셀 값을 그대로 받음 (계산 없음) |
| 은닉층 1 | 256 | 짧은 획, 곡선 조각 같은 단순한 특징을 찾음 |
| 은닉층 2 | 128 | 단순한 특징을 조합해 '위쪽 고리', '아래로 긴 줄' 같은 더 큰 모양을 알아봄 |
| 출력층 | 10 | 0~9 각 숫자에 대한 점수를 냄 |

모든 뉴런이 앞 층의 모든 뉴런과 연결되어 있어서 **완전 연결층(Fully Connected Layer, Dense Layer)**이라고도 부릅니다.

### 7-3. 활성화 함수: ReLU

```
 ReLU(z) = max(0, z)

   출력
    │      ╱
    │    ╱
    │  ╱
 ───┼──────── z
    │(음수는 0)
```

- 음수는 0, 양수는 그대로 내보냅니다.
- **왜 필요한가요?** 곱하고 더하는 선형 계산만 여러 층 쌓으면 결국 **직선 하나**와 같아집니다. 중간에 꺾인 함수를 넣어야 구불구불하고 복잡한 경계를 배울 수 있습니다. 이를 비선형성(Non-linearity)이라고 합니다.
- ReLU는 계산이 간단하고 깊은 신경망에서도 학습이 잘 되어 가장 많이 쓰입니다.

### 7-4. 출력층: 소프트맥스(Softmax)

출력층 뉴런 10개가 낸 점수를 **모두 더하면 1이 되는 확률**로 바꿉니다.

```
 확률_k = e^(점수_k) / (e^(점수_0) + e^(점수_1) + ... + e^(점수_9))
```

**계산 예시** (클래스 3개로 줄여서)

| 클래스 | 점수 | e^점수 | 확률 |
|---|---|---|---|
| A | 2.0 | 7.389 | 7.389 / 11.212 = **0.659** |
| B | 1.0 | 2.718 | 2.718 / 11.212 = **0.242** |
| C | 0.1 | 1.105 | 1.105 / 11.212 = **0.099** |
| 합계 | | 11.212 | **1.000** |

확률이 가장 높은 클래스를 예측값으로 고릅니다. 이것을 **argmax**라고 합니다. 2단계 그림판의 막대그래프가 바로 이 확률 10개입니다.

### 7-5. 모델이 배워야 할 숫자(파라미터)는 몇 개인가?

| 연결 | 계산 | 개수 |
|---|---|---|
| 입력 → 은닉1 | 784 × 256 + 256(편향) | 200,960 |
| 은닉1 → 은닉2 | 256 × 128 + 128 | 32,896 |
| 은닉2 → 출력 | 128 × 10 + 10 | 1,290 |
| **합계** | | **235,146** |

**학습이란 이 23만여 개의 숫자를 정답을 잘 맞히는 값으로 조금씩 맞춰 가는 과정입니다.** 처음에는 작은 무작위 값으로 시작합니다. sklearn은 층의 크기에 맞춰 범위를 정하는 Glorot 방식으로 초깃값을 정합니다.

## 8. 학습 원리: 모델은 어떻게 배우는가?

### 8-1. 학습 한 번의 4단계

```
 ┌──────────────────────────────────────────────────────────────┐
 │  1) 순전파          사진 128장 → 모델 → 숫자별 확률            │
 │        ↓                                                     │
 │  2) 손실 계산        예측 확률 vs 정답 → "얼마나 틀렸나" (숫자 하나) │
 │        ↓                                                     │
 │  3) 역전파          손실을 줄이려면 각 가중치를 어느 쪽으로 바꿀지 계산 │
 │        ↓                                                     │
 │  4) 가중치 갱신      그 방향으로 조금(학습률만큼) 이동             │
 └──────────────────────── 반복 ────────────────────────────────┘
```

| 단계 | 영어 | 설명 |
|---|---|---|
| 1) 순전파 | Forward propagation | 입력을 층마다 통과시켜 확률을 계산 |
| 2) 손실 계산 | Loss computation | 교차 엔트로피로 틀린 정도를 숫자 하나로 표현 |
| 3) 역전파 | Backpropagation | 출력층에서 입력층 쪽으로 거꾸로 가며 가중치별 기울기(Gradient) 계산 |
| 4) 갱신 | Update | Adam 방식으로 기울기의 반대 방향으로 가중치를 이동 |

### 8-2. 손실 함수: 교차 엔트로피(Cross-Entropy)

모델이 **정답 클래스에 준 확률**이 높을수록 손실이 작아지도록 만든 함수입니다.

```
 손실 = −log(정답 클래스에 준 확률)
```

| 정답이 7일 때, 7에 준 확률 | 손실 | 해석 |
|---|---|---|
| 0.99 | 0.010 | 거의 완벽 |
| 0.90 | 0.105 | 잘 맞힘 |
| 0.50 | 0.693 | 반반 |
| 0.10 | 2.303 | 많이 틀림 |
| 0.01 | 4.605 | 자신 있게 틀림 → 큰 벌점 |

- 정답을 맞혔는지만 보는 게 아니라 **얼마나 확신했는지**까지 반영합니다.
- 틀린 답을 자신 있게 낼수록 벌점이 급격히 커집니다.
- 학습 중 화면의 `loss = ...`가 이 값의 평균입니다. 작아질수록 잘 배우고 있다는 뜻입니다. sklearn이 보여 주는 값에는 9-2절의 L2 규제 벌점도 조금 더해져 있습니다.

### 8-3. 경사 하강법(Gradient Descent): 안개 낀 산 내려가기

```
 손실
  │ ╲                    ╱
  │  ╲                  ╱
  │   ╲     ●→        ╱        ● : 현재 가중치
  │    ╲      ↘      ╱         → : 기울기 반대 방향으로 한 걸음
  │     ╲       ↘  ╱
  │      ╲___★___╱             ★ : 손실이 가장 낮은 곳 (목표)
  └──────────────────── 가중치
```

- 짙은 안개 속에서 산 아래(손실이 가장 낮은 곳)로 내려가려면, 발밑의 **기울기**를 느끼고 내리막 쪽으로 한 걸음씩 가면 됩니다.
- **기울기(Gradient)** = 가중치를 조금 바꿨을 때 손실이 얼마나 변하는지
- **학습률(Learning rate)** = 한 걸음의 보폭. 이 예제는 0.001입니다.
  - 너무 크면 골짜기를 건너뛰어 왔다 갔다 하거나 오히려 손실이 커집니다.
  - 너무 작으면 내려가는 데 한참 걸립니다.

### 8-4. 역전파(Backpropagation)

가중치가 23만 개나 되는데, 각각을 어느 방향으로 바꿔야 할지 어떻게 알까요?

- 출력층에서 손실을 계산한 뒤, **연쇄 법칙(Chain Rule)**을 이용해 "이 가중치가 손실에 얼마나 기여했나"를 층을 거슬러 올라가며 한 번에 계산합니다.
- 비유: 팀 프로젝트가 실패했을 때, 최종 결과물부터 거꾸로 거슬러 가며 각 단계 담당자의 책임 비율을 따지는 것과 비슷합니다.
- 역전파 덕분에 가중치가 아무리 많아도 기울기를 효율적으로 구할 수 있습니다.

### 8-5. 미니 배치, 반복, 에포크

| 용어 | 뜻 | 이 예제 |
|---|---|---|
| 미니 배치(Mini-batch) | 한 번에 보는 사진 묶음 | 128장 |
| 반복(Step, Iteration) | 미니 배치 하나로 가중치를 한 번 고치는 것 | 에포크당 약 422번 (54,000 ÷ 128) |
| 에포크(Epoch) | 학습 데이터 전체를 한 바퀴 보는 것 | 최대 30번 |

**왜 미니 배치를 쓰나요?**
- 54,000장을 다 보고 한 번 고치면 너무 느립니다.
- 1장마다 고치면 방향이 들쭉날쭉합니다.
- 128장 정도씩 보고 고치면 속도와 안정성의 균형이 좋습니다. 이렇게 일부만 뽑아 기울기를 추정하는 방식을 **확률적 경사 하강법(SGD, Stochastic Gradient Descent)**이라고 합니다.

> sklearn의 화면 출력에서 `Iteration`은 **에포크**를 뜻합니다.

### 8-6. Adam 최적화

**Adam**(Adaptive Moment Estimation)은 경사 하강법을 개선한 방법으로, 현재 가장 널리 쓰입니다.

- **관성(Momentum):** 이전에 가던 방향을 어느 정도 유지해서, 울퉁불퉁한 지형에서도 덜 흔들리고 빠르게 내려갑니다.
- **적응형 보폭(Adaptive learning rate):** 가중치마다 보폭을 따로 자동 조절합니다. 자주 크게 바뀌던 가중치는 조심스럽게, 거의 안 바뀌던 가중치는 과감하게 움직입니다.
- 덕분에 학습률을 세밀하게 고르지 않아도 대체로 잘 작동합니다.

## 9. 과적합과 그 대처법

### 9-1. 과적합(Overfitting)이란?

```
 정확도
  │          ┌─────────── 학습 정확도 (계속 오름)
  │       ╱──
  │    ╱─── ─ ─ ─ ─ ╲     검증 정확도 (어느 순간부터 정체·하락)
  │  ╱             ↑
  │╱          여기서 멈추는 게 최선
  └────────────────────── 에포크
```

- **교과서 문제의 답을 외워 버려서, 새 문제는 못 푸는 상태**입니다.
- 학습 데이터 정확도는 계속 오르는데 검증·시험 정확도는 오르지 않거나 떨어집니다.
- 반대로 너무 단순해서 학습 데이터조차 잘 못 맞히는 상태는 **과소적합(Underfitting)**이라고 합니다.

### 9-2. L2 규제(L2 Regularization), `alpha=0.0001`

- 손실에 **"가중치 크기의 제곱합 × alpha"**를 벌점으로 더합니다.
- 가중치가 지나치게 커지면 벌점이 커지므로, 모델이 특정 픽셀 몇 개에만 과하게 의존하지 않고 여러 특징을 고르게 쓰게 됩니다.
- alpha를 키우면 규제가 강해집니다. 과적합은 줄지만 너무 크면 과소적합이 됩니다.

### 9-3. 조기 종료(Early Stopping)

- 에포크마다 **검증 데이터 정확도**를 확인합니다.
- `n_iter_no_change=4`: 4에포크 연속 나아지지 않으면 학습을 멈춥니다.
- 멈춘 뒤에는 **검증 점수가 가장 좋았던 때의 가중치**로 되돌립니다.
- `max_iter=30`은 상한선일 뿐이고, 실제로는 그 전에 멈추는 경우가 많습니다.

## 10. 평가: 얼마나 잘 맞히는가?

학습이 끝나면 **한 번도 본 적 없는 시험 데이터 10,000장**으로 평가합니다.

### 10-1. 정확도(Accuracy)

```
 정확도 = 맞힌 개수 / 전체 개수
```

가장 직관적인 지표입니다. 하지만 **클래스 비율이 한쪽으로 치우친 데이터**에서는 착시가 생깁니다. 예를 들어 사기 거래가 1%뿐이면, 무조건 "정상"이라고만 답해도 정확도가 99%입니다. MNIST는 숫자별 개수가 비슷해서 정확도만으로도 대략 판단할 수 있습니다.

### 10-2. 혼동 행렬(Confusion Matrix)

행은 **실제 정답**, 열은 **모델의 예측**입니다. 아래는 이해를 돕기 위한 일부 예시입니다.

| 실제 \ 예측 | 3 | 5 | 8 |
|---|---|---|---|
| **3** | **990** | 8 | 6 |
| **5** | 7 | **870** | 5 |
| **8** | 9 | 4 | **950** |

- **대각선** = 맞힌 개수
- **나머지 칸** = 무엇을 무엇으로 착각했는지. 예) 실제 3을 5로 착각한 경우 8번
- 코드는 가장 많이 헷갈린 숫자 쌍 5개를 따로 출력합니다. 흔히 4↔9, 3↔5, 7↔2처럼 모양이 비슷한 쌍이 나옵니다.

### 10-3. 정밀도, 재현율, F1 점수

숫자 7을 기준으로 보면:

| 지표 | 질문 | 계산 |
|---|---|---|
| **정밀도(Precision)** | 모델이 "7"이라고 한 것 중 진짜 7은 몇 %? | 진짜 7을 7로 예측 / 7로 예측한 전체 |
| **재현율(Recall)** | 진짜 7 중에서 모델이 찾아낸 건 몇 %? | 진짜 7을 7로 예측 / 진짜 7 전체 |
| **F1 점수** | 둘 다 고려하면? | 2 × 정밀도 × 재현율 / (정밀도 + 재현율) |

- 정밀도가 낮다 → 헛다리를 많이 짚음 (다른 숫자를 7이라고 함)
- 재현율이 낮다 → 많이 놓침 (진짜 7을 다른 숫자라고 함)
- 실제 업무에서는 어느 쪽 실수가 더 비싼지에 따라 중요한 지표가 달라집니다. 암 진단은 재현율, 스팸 필터는 정밀도가 더 중요합니다.

코드는 `classification_report()`로 숫자별 정밀도·재현율·F1과 개수(support)를 한 번에 출력합니다.

### 10-4. 기대 성능

이 구성(784-256-128-10 MLP, Adam, 조기 종료)은 MNIST 시험 데이터에서 일반적으로 **약 97.5~98.5%** 정확도를 냅니다. 실제 수치는 실행 결과로 확인하세요. `random_state=42`로 고정했기 때문에 같은 환경이면 매번 같은 결과가 나옵니다.

## 11. 활용(추론): 내가 쓴 숫자 인식하기

학습된 모델로 새 데이터를 예측하는 것을 **추론(Inference)**이라고 합니다. `2_손글씨_숫자_인식하기.py`가 이 단계를 담당합니다.

### 핵심: 새 데이터를 학습 데이터와 같은 모양으로 만들기

모델은 MNIST 사진만 보고 배웠습니다. 그림판에 그린 그림은 크기, 위치, 굵기가 제각각이므로 **MNIST와 같은 규칙으로 바꿔 줘야** 잘 알아봅니다.

```
 그림판(280×280)
      │
      ▼  ① 숫자가 있는 부분만 잘라 내기 (경계 상자, Bounding box)
      ▼  ② 긴 쪽이 20픽셀이 되도록 축소 (가로세로 비율 유지)
      ▼  ③ 28×28 검은 도화지 가운데에 붙이기
      ▼  ④ 무게중심(Center of mass)을 정중앙(14, 14)으로 이동
      ▼  ⑤ ÷255 정규화, 784칸으로 평탄화
      ▼
 모델.predict_proba() → 0~9 확률 10개 → 가장 큰 값이 답
```

> 💡 **분류 실무의 교훈:** 모델 성능이 실제 현장에서 떨어지는 가장 흔한 이유는 **학습 데이터와 실제 데이터의 분포 차이(Distribution shift)**입니다. 예를 들어 숫자를 아주 작게 쓰거나 구석에 쓰면, 이 전처리가 없을 때 모델이 잘 틀립니다. 그림판 오른쪽 아래의 "모델이 본 28×28 사진"으로 전처리 결과를 직접 확인할 수 있습니다.

### 확신도(Confidence)

그림판은 가장 높은 확률 값을 **확신도**로 보여 줍니다. 확신도가 낮으면 모델이 헷갈리고 있다는 뜻입니다. 실무에서는 확신도가 일정 기준보다 낮을 때 사람이 다시 확인하도록 설계하기도 합니다.

## 12. 하이퍼파라미터 정리와 실습 과제

**하이퍼파라미터(Hyperparameter)**는 모델이 스스로 배우는 값(가중치)이 아니라, **사람이 학습 전에 정해 주는 설정값**입니다.

| 하이퍼파라미터 | 값 | 의미 | 키우면 | 줄이면 |
|---|---|---|---|---|
| `hidden_layer_sizes` | (256, 128) | 은닉층 수와 뉴런 수 | 표현력↑, 느려짐, 과적합 위험↑ | 빠름, 과소적합 위험↑ |
| `activation` | relu | 활성화 함수 | — | — |
| `solver` | adam | 최적화 방법 | — | — |
| `learning_rate_init` | 0.001 | 학습률(보폭) | 빠르지만 불안정 | 안정적이지만 느림 |
| `batch_size` | 128 | 미니 배치 크기 | 안정적, 메모리↑ | 흔들림↑, 일반화에 도움될 때도 |
| `max_iter` | 30 | 최대 에포크 수 | 더 오래 학습 | 덜 학습 |
| `alpha` | 0.0001 | L2 규제 강도 | 과적합↓, 과소적합 위험↑ | 과적합 위험↑ |
| `early_stopping` | True | 조기 종료 사용 | — | — |
| `validation_fraction` | 0.1 | 검증 데이터 비율 | — | — |
| `n_iter_no_change` | 4 | 몇 번 정체되면 멈출지 | 더 끈기 있게 학습 | 빨리 멈춤 |
| `random_state` | 42 | 난수 고정 | — | — |

### 수업용 실습 과제 제안

`모델_만들기()`의 값을 하나씩 바꿔 가며 다시 학습하고, 결과를 표로 비교해 보세요.

3. **규제:** `alpha`를 `0.01`, `1.0`으로 키우면 학습·검증 정확도의 차이는 어떻게 변하나요?
4. **조기 종료 끄기:** `early_stopping=False`, `max_iter=50`으로 하면 과적합이 보이나요?
5. **활성화 함수:** `activation="logistic"`(시그모이드)으로 바꾸면 학습 속도는 어떻게 달라지나요?
6. **오분류 분석:** 가장 많이 헷갈린 숫자 쌍은 무엇인가요? 사람이 봐도 헷갈릴 만한가요?

## 13. 다른 분류 방법과 비교

같은 MNIST 문제를 다른 분류 방법으로도 풀 수 있습니다. 아래 정확도는 일반적으로 알려진 **대략적인 수준**이며, 설정에 따라 달라집니다.

| 방법 | 핵심 아이디어 | MNIST 정확도(대략) | 장점 | 단점 |
|---|---|---|---|---|
| 로지스틱 회귀 (Logistic Regression) | 픽셀의 가중합으로 클래스별 점수 계산 (선형) | 약 92% | 빠름, 해석 쉬움 | 복잡한 모양 구분이 어려움 |
| k-최근접 이웃 (k-NN) | 가장 비슷한 학습 사진 k장의 다수결 | 약 97% | 학습 과정이 없음, 직관적 | 예측이 느리고 메모리를 많이 씀 |
| 서포트 벡터 머신 (SVM, RBF 커널) | 클래스 사이 간격(마진)을 최대로 하는 경계 | 약 98% | 정확도 높음 | 데이터가 많으면 학습이 매우 느림 |
| 결정 트리 (Decision Tree) | 예/아니오 질문을 나무처럼 반복 | 약 87~88% | 해석 쉬움 | 단독으로는 과적합되기 쉬움 |
| 랜덤 포레스트 (Random Forest) | 결정 트리 수백 개의 다수결 | 약 97% | 튼튼하고 설정이 쉬움 | 모델이 크고 해석이 어려움 |
| **다층 퍼셉트론 (MLP)** ← 이 예제 | 뉴런을 여러 층으로 쌓아 비선형 경계 학습 | **약 98%** | 정확도 높음, 확장 쉬움 | 하이퍼파라미터가 많음, 해석 어려움 |
| 합성곱 신경망 (CNN) | 이미지의 공간 구조를 그대로 활용 | 99% 이상 | 이미지에서 최고 수준 | 계산량이 많고 GPU가 있으면 유리 |

> 📌 표 형태의 일반 비즈니스 데이터(고객, 매출, 설문 등)에서는 랜덤 포레스트나 그래디언트 부스팅(XGBoost, LightGBM)이 신경망보다 좋은 경우가 많습니다. 반면 이미지, 음성, 텍스트처럼 **원시 데이터(Raw data)**에서는 신경망(딥러닝)이 압도적입니다.

## 14. 머신러닝과 딥러닝, 그리고 다음 단계

```
 ┌─────────────────────────────────── 인공지능 (AI)
 │  ┌────────────────────────────── 머신러닝 (Machine Learning)
 │  │   로지스틱 회귀, SVM, 랜덤 포레스트, k-NN ...
 │  │  ┌───────────────────────── 딥러닝 (Deep Learning)
 │  │  │   여러 층의 신경망: MLP, CNN, RNN, Transformer ...
 │  │  └─────────────────────────
 │  └──────────────────────────────
 └───────────────────────────────────
```

### 이 예제는 머신러닝일까, 딥러닝일까?

- MLP는 **인공 신경망**이므로 딥러닝 계열의 출발점입니다.
- 은닉층이 2개인 이 모델은 '얕은 딥러닝'으로 볼 수 있습니다. 보통 은닉층이 여러 개일 때 '깊다(Deep)'고 합니다.
- 학습 원리(순전파 → 손실 → 역전파 → 경사 하강법)는 수백 층짜리 최신 딥러닝 모델과 **완전히 같습니다.** 이 예제를 이해하면 딥러닝의 핵심을 이해한 것입니다.

### 특징 공학(Feature Engineering) vs 표현 학습(Representation Learning)

| | 전통적 머신러닝 | 딥러닝 |
|---|---|---|
| 특징 만들기 | 사람이 직접 설계 (예: "고리가 몇 개인가", "세로획 길이") | 모델이 데이터에서 스스로 학습 |
| 이 예제에서 | — | 은닉층이 획, 곡선 같은 특징을 스스로 찾아냄 |

### 다음 단계: 합성곱 신경망(CNN)

MLP는 사진을 한 줄로 펴서 위치 정보를 잃습니다. **CNN(Convolutional Neural Network)**은 작은 돋보기(필터, Filter)로 사진을 훑으며 주변 픽셀과의 관계를 그대로 활용합니다.

- 숫자가 조금 옆으로 움직여도 같은 숫자로 잘 알아봅니다.
- 같은 필터를 사진 전체에서 함께 쓰기 때문에 파라미터 수도 오히려 적습니다.
- MNIST 정확도가 99% 이상으로 올라갑니다.
- PyTorch나 TensorFlow/Keras 같은 딥러닝 전용 라이브러리로 구현합니다.

## 15. 용어 사전

| 한국어 | 영어 | 뜻 |
|---|---|---|
| 지도 학습 | Supervised Learning | 정답이 붙은 데이터로 배우는 방식 |
| 분류 | Classification | 정해진 범주 중 하나를 예측 |
| 다중 클래스 분류 | Multi-class Classification | 범주가 3개 이상인 분류 |
| 표본 | Sample | 데이터 한 건 (사진 한 장) |
| 특징 | Feature | 입력 변수 하나 (픽셀 하나) |
| 라벨, 목표 변수 | Label, Target | 정답 |
| 학습/검증/시험 데이터 | Training / Validation / Test set | 공부용 / 중간 점검용 / 최종 평가용 데이터 |
| 데이터 유출 | Data Leakage | 평가용 정보가 학습에 섞여 성능이 부풀려지는 것 |
| 정규화 | Normalization | 값의 범위를 일정하게 맞추는 것 |
| 평탄화 | Flatten | 2차원 격자를 1차원 목록으로 펴는 것 |
| 뉴런 | Neuron | 가중합 + 활성화 함수로 이루어진 계산 단위 |
| 가중치 / 편향 | Weight / Bias | 모델이 학습하는 숫자 |
| 파라미터 | Parameter | 모델이 학습하는 값 전체 (가중치 + 편향) |
| 하이퍼파라미터 | Hyperparameter | 사람이 학습 전에 정하는 설정값 |
| 은닉층 | Hidden Layer | 입력층과 출력층 사이의 층 |
| 완전 연결층 | Fully Connected (Dense) Layer | 앞 층의 모든 뉴런과 연결된 층 |
| 활성화 함수 | Activation Function | 뉴런 출력에 비선형성을 주는 함수 (ReLU 등) |
| 소프트맥스 | Softmax | 점수를 합이 1인 확률로 바꾸는 함수 |
| 손실 함수 | Loss Function | 예측이 얼마나 틀렸는지 재는 함수 |
| 교차 엔트로피 | Cross-Entropy | 분류에서 쓰는 대표적인 손실 함수 |
| 순전파 | Forward Propagation | 입력에서 출력 방향으로 계산 |
| 역전파 | Backpropagation | 출력에서 입력 방향으로 기울기 계산 |
| 기울기 | Gradient | 가중치를 바꿀 때 손실이 변하는 정도와 방향 |
| 경사 하강법 | Gradient Descent | 기울기 반대 방향으로 가중치를 조금씩 고치는 방법 |
| 확률적 경사 하강법 | SGD (Stochastic Gradient Descent) | 일부 데이터(미니 배치)로 기울기를 추정하는 경사 하강법 |
| 학습률 | Learning Rate | 가중치를 한 번에 고치는 보폭 |
| 미니 배치 | Mini-batch | 한 번에 보는 데이터 묶음 |
| 에포크 | Epoch | 학습 데이터 전체를 한 바퀴 보는 것 |
| 옵티마이저 | Optimizer | 가중치를 고치는 방법 (SGD, Adam 등) |
| 과적합 / 과소적합 | Overfitting / Underfitting | 외워 버림 / 덜 배움 |
| 규제 | Regularization | 과적합을 막기 위해 모델에 제약을 거는 것 |
| 조기 종료 | Early Stopping | 검증 성능이 나아지지 않으면 학습을 멈추는 것 |
| 정확도 | Accuracy | 전체 중 맞힌 비율 |
| 정밀도 | Precision | 양성이라 예측한 것 중 실제 양성 비율 |
| 재현율 | Recall | 실제 양성 중 찾아낸 비율 |
| F1 점수 | F1-score | 정밀도와 재현율의 조화 평균 |
| 혼동 행렬 | Confusion Matrix | 실제와 예측을 교차해 센 표 |
| 추론 | Inference | 학습된 모델로 새 데이터를 예측하는 것 |
| 분포 차이 | Distribution Shift | 학습 데이터와 실제 데이터의 성격이 다른 것 |
| 합성곱 신경망 | CNN (Convolutional Neural Network) | 이미지의 공간 구조를 활용하는 신경망 |
